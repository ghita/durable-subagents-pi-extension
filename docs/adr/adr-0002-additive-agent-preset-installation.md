# ADR-0002: Additive Installation of Packaged Agent Presets

Package-shipped agent presets will be copied into Pi's user-global agent library only through an explicit `/agents install` command, which installs all packaged presets whose IDs are missing. The package ships only `scout` (inherited model, low thinking) and `review` (inherited model, high thinking), reusing their current instructions and `read`/`bash` allowlists. Both enable Code Mode through a separate `codemode: true` preset setting, so scripts can compose those tools without granting additional tools; Code Mode's `models.*` helpers are disabled. Existing preset IDs are never overwritten, including during package upgrades; copied files remain after package removal, and users are told to run `/reload` before using newly installed presets. This favors preserving user-owned definitions over automatic updates or cleanup, while `/agents presets` directs users to install when packaged defaults are absent.
