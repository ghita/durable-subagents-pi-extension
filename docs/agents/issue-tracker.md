# Issue Tracker Instructions

- **Repository:** `ghita/durable-subagents-pi-extension`
- **Canonical URL:** https://github.com/ghita/durable-subagents-pi-extension
- **Tracker:** GitHub Issues; use the `gh` CLI.
- Draft proposed tickets and obtain the user's approval before creating issues. Approval applies only to the exact reviewed breakdown; ask again if it materially changes.
- Do not close or modify a parent/source issue. When applicable, link the parent in the ticket body and use native sub-issue support if available.
- Prefer native GitHub issue blocking/dependency relationships when supported by the repository and installed tooling. Otherwise include blockers in the issue body as `Blocked by: #<number>`.
- Use the `ready-for-agent` label for approved implementation tickets. Check that it exists before publishing; ask the user before creating it if missing.
